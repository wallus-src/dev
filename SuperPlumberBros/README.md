# Super Plumber Bros

A native iOS side-scrolling platformer in the spirit of classic 8-bit plumbers,
built with **Swift + SpriteKit**. Original pixel-art sprites and synthesized
sound effects — no copyrighted assets.

## Features

- **Hand-tuned tile physics** — custom axis-separated AABB collision at a fixed
  120 Hz timestep (no SpriteKit physics engine): coyote time (0.09 s), jump
  buffering (0.12 s), variable jump height, skid, walk vs. run speeds.
- **A complete level** — 184 tiles of ground, pits, three pipes, stairs,
  question blocks (coins + mushrooms), brick clusters, a flagpole, and a castle.
- **Enemies** — Goombas (walk, squash when stomped) and Koopas (stomp into a
  shell, kick it, sliding shells clear out other enemies).
- **Power-ups** — mushrooms make you big (two tiles tall, can smash bricks,
  shrinks instead of dying on a hit). 100 coins = extra life.
- **HUD & flow** — score / coins / world / timer, title screen, pause,
  game-over & course-clear screens, score tally for remaining time.
- **Touch controls** — ◀ ▶ move, **A** jump, **B** run (safe-area aware).
- **Keyboard controls** (iPad / simulator) — arrows move, `Z`/`Space` jump,
  `X`/`Shift` run, `Return` start / restart.
- **Sound** — 17 chiptune-style WAVs (jumps, coin, stomp, bump, break, power-up,
  grow/shrink, kick, flagpole, death, game-over, overworld loop) generated by
  `tools/gen_sounds.py`.

## Build & run

Requires Xcode 16+ and [XcodeGen](https://github.com/yonsm/XcodeGen)
(`brew install xcodegen`).

```sh
cd SuperPlumberBros
xcodegen generate          # regenerates SuperPlumberBros.xcodeproj from project.yml
open SuperPlumberBros.xcodeproj
# pick an iPhone simulator and press ⌘R, or build headless:
xcodebuild -scheme SuperPlumberBros \
  -destination 'platform=iOS Simulator,name=iPhone 17' build
```

The game is **landscape-only**.

### Autopilot demo mode

Launch with `-autopilot` to watch the game play itself (auto-start, holds
right+run, jumps at walls/gaps/enemies, bumps blocks, chases mushrooms):

```sh
xcrun simctl install booted <path>/SuperPlumberBros.app
xcrun simctl launch booted com.wallus.superplumberbros -autopilot
```

## Project layout

```
SuperPlumberBros/
  project.yml              # XcodeGen spec (bundle id com.wallus.superplumberbros)
  SuperPlumberBros/
    Sources/
      AppDelegate.swift        window boot, presents TitleScene
      GameViewController.swift SKView config + keyboard (UIKey) handling
      TitleScene.swift         title screen, tap/Return to start
      GameScene.swift          level build, fixed-step loop, camera, HUD,
                               touch controls, interactions, autopilot
      Entities.swift           Entity/Player/Goomba/Koopa/MushroomItem + physics
      Level.swift              tile map (184×15) + layout helpers
      Sprites.swift            string-grid pixel art for every sprite
      PixelArt.swift           palette → CGImage → SKTexture (.nearest)
      Audio.swift              sound playback
    Resources/Sounds/          generated WAV files
    Info.plist                 orientation + launch settings
  tools/gen_sounds.py        regenerates all WAVs (pure Python, no deps)
```

## Notes

- All artwork is hand-drawn string grids rendered at 1 pt/px with nearest
  neighbor filtering — an homage, not a copy.
- The camera never scrolls backwards (classic rule) and clamps the player at
  its left edge.
